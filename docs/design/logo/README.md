# CUMT Nexus Logo Drafts

这个目录只放设计阶段文件, 暂不接入站点代码。

## 文件

- `concept-sheet.svg`: 三个方向的对比总览。
- `concept-sheet.preview.png`: 总览 SVG 的浏览器渲染预览。
- `concept-a-lockup.svg`: 推荐方向 A 的横版 logo。
- `concept-a-mark.svg`: 推荐方向 A 的独立图标。

## 设计目标

- 保留现在左侧栏 `CN` 的识别基础, 不突然换成陌生图形。
- 图形语言更贴近站内的直线、低圆角、信息网络感。
- 避免大圆角色块按钮感、潮流渐变、过强装饰。
- 适合深色产品界面, 也能迁移到浅色头像、favicon、启动页。

## 推荐方向

首选 `方案 A - CN Nexus Mark`。

它用一个开放的 `C` 表达校园社区入口, 用中间的斜向连接线表达 Nexus 的连接关系。相比直接写 `CN`, 它更像正式产品标识, 但仍然能继承当前站点已经建立的识别。

## 当前判断

- A: 最稳, 和现有版本关系最近, 适合继续细化。
- B: 网络感更强, 但更像通用科技 logo。
- C: 更产品化, 但字母识别弱, 容易变成普通应用图标。
